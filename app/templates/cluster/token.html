On the new machine

Install Incus and leave it unconfigured, then run incus admin init. Say yes to clustering, give the machine's own address, say yes to joining an existing cluster, and paste the token.

Or answer everything at once:

cat <<'PRESEED' | incus admin init --preseed

  enabled: true
  server_address: its-address:8443
  cluster_token: {{ token }}
